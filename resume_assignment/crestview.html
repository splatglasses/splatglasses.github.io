Crestview High School Infrastructure Upgrade

I assisted in orchestrating an infrastructure upgrade for Crestview High School's cybersecurity lab, which serves over 100 students annually.

Description

The project focused on modernizing the lab environment to better support hands-on cybersecurity training and streamline system management for faculty and students.

A new Active Directory domain and a Windows Server Update Services (WSUS) server were deployed and maintained to centralize user management, policy enforcement, and patch distribution.
